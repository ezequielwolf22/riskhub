GETTING STARTED
─────────────────────────────────────────────────────────────────────────────

1. Get API Keys (optional but recommended):
   - HIBP: https://haveibeenpwned.com/API/v3 (free)
   - VirusTotal: https://www.virustotal.com (free)
   - Others: Intelligence X, LeakCheck, GitHub (optional)

2. Configure .env:
   RISKHUB_HIBP_API_KEY=your-key-here
   RISKHUB_VIRUSTOTAL_API_KEY=your-key-here

3. Restart application:
   uvicorn app.main:app --reload  (dev)
   bash /opt/riskhub/deploy.sh     (prod)

4. Access OSINT:
   http://localhost:8000/#/osint

5. Start scanning:
   - Click "OSINT" in sidebar
   - Select scan type (email/URL/username)
   - Enter target
   - Click "Iniciar escaneo"
   - Monitor progress and results
